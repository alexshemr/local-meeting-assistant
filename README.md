# Local Meeting Assistant

Приложение для macOS: записывает рабочие встречи, распознаёт речь, разделяет участников по голосам
и готовит саммари. Запись, распознавание и разделение голосов выполняются на компьютере; саммари
по умолчанию тоже готовит локальная модель.

Требования: Mac на Apple Silicon (рассчитано на M3 / 16 ГБ), macOS 15 или новее, около 12 ГБ под модели.

## Что умеет

- Пишет микрофон и системный звук одновременно, в том числе в наушниках. Работает с любым сервисом звонков.
- Предлагает начать запись, когда начался звонок, и завершить, когда он закончился. Сама запись не начинается.
- Распознаёт русскую речь с английскими терминами, ставит временные метки, разделяет спикеров.
- Запоминает названные голоса и узнаёт их на следующих встречах.
- Готовит саммари: краткое содержание, обсуждённые вопросы, решения, задачи, открытые вопросы, следующие шаги.
  Саммари можно править, перегенерировать и дорабатывать замечаниями — текстом или голосом.
- По запросу пишет follow-up в трёх форматах. Письмо никуда не отправляется.
- Импортирует готовые записи (MP3, M4A, WAV, FLAC, MP4, MOV; для MKV, WebM и OGG нужен ffmpeg).
- Делит и обрезает встречи; замечает, что во время записи один звонок сменился другим.
- Ведёт карточки людей: встречи с человеком и сводка договорённостей.
- Берёт из календаря macOS тему встречи и список приглашённых: видно, кто из них говорил.
- Складывает транскрипции и саммари в папку обычными Markdown- и JSON-файлами — для AI-агентов.

## Установка

1. Скачайте `LocalMeetingAssistant-<версия>.dmg` со страницы Releases.
2. Перетащите приложение в «Программы» и запустите.
3. Откройте **Настройки → Локальные модели → «Скачать всё необходимое»** (около 9 ГБ).
4. При первой записи разрешите доступ к **микрофону** и **записи системного аудио**.

Отдельно ничего ставить не нужно: llama.cpp встроен в приложение, модели оно скачивает само.

## Что остаётся на компьютере

| Этап | Где выполняется |
|---|---|
| Запись, эхоподавление | на компьютере |
| Распознавание речи, разделение голосов | на компьютере |
| Саммари, follow-up, сводки | на компьютере — встроенная модель или Ollama; в облаке — если выбран Claude Code или Codex |
| Календарь | читаются календари macOS, запросов в сеть приложение не делает |

Облачный движок включается только вручную в настройках; при его выборе транскрипция встречи уходит
в Anthropic или OpenAI через установленную у вас программу и ваш вход в ней.

## Модели для саммари

Приложение само находит доступные движки и показывает их в настройках:

- встроенная Gemma 4 (GGUF через llama.cpp) или свой файл GGUF;
- модели [Ollama](https://ollama.com), если она установлена и запущена;
- [Claude Code](https://claude.com/claude-code) и Codex, если они установлены и в них выполнен вход.

Режим нагрузки настраивается: на время звонков и записи тяжёлая обработка приостанавливается.

## Календарь

Используются календари macOS. Чтобы подключить Google Календарь, добавьте аккаунт Google
в «Системные настройки → Учётные записи интернета» и включите для него «Календари».

## База знаний для AI-агентов

Папка выбирается в настройках (по умолчанию `~/Documents/Meeting Knowledge Base`):

```
README.md              описание структуры для агента
index.md, index.json   перечень всех встреч
meetings/
  2026-11-10_15-00_интеграция-офлайн-заказов_3f2a/
    meeting.json       метаданные, участники, событие календаря
    summary.md         саммари
    transcript.md      полная транскрипция
```

Follow-up и сводки по людям в папку не попадают.

## Где лежат данные

| Что | Где |
|---|---|
| Записи и рабочие данные встреч | `~/Library/Application Support/LocalMeetingAssistant/Meetings` |
| Модели | `~/Library/Application Support/LocalMeetingAssistant/Models` |
| Люди и голоса | `~/Library/Application Support/LocalMeetingAssistant/voices.json` |
| База знаний | папка из настроек |

## Сборка из исходников

Нужны только Command Line Tools (`xcode-select --install`), Xcode не требуется.

```bash
scripts/build-app.sh   # dist/Local Meeting Assistant.app
scripts/make-dmg.sh    # dist/LocalMeetingAssistant-<версия>.dmg
```

Скрипты скачивают зафиксированные сборки llama.cpp и модели эхоподавления, проверяют контрольные суммы
и вкладывают их в приложение.

Чтобы приложение запускалось без предупреждений Gatekeeper, образ нужно подписать сертификатом
Developer ID и нотаризовать:

```bash
SIGN_IDENTITY="Developer ID Application: Имя (TEAMID)" scripts/make-dmg.sh
xcrun notarytool submit dist/LocalMeetingAssistant-*.dmg --keychain-profile <профиль> --wait
xcrun stapler staple dist/LocalMeetingAssistant-*.dmg
```

Без подписи приложение запустится только после ручного разрешения в
«Системные настройки → Конфиденциальность и безопасность».

## Как это устроено

| Задача | Технология |
|---|---|
| Интерфейс | Swift, SwiftUI (строка меню + окно) |
| Системный звук | Core Audio process tap — без виртуальных устройств |
| Распознавание речи | Whisper large-v3 turbo через [WhisperKit](https://github.com/argmaxinc/WhisperKit) (CoreML) |
| Разделение спикеров | [FluidAudio](https://github.com/FluidInference/FluidAudio) (CoreML) |
| Эхоподавление | [LocalVQE](https://github.com/localai-org/LocalVQE) (Apache-2.0); детектор эха и схема встраивания — по мотивам [meeting-transcriber](https://github.com/pasrom/meeting-transcriber) (MIT) |
| Саммари и follow-up | Gemma 4 (GGUF) через встроенный [llama.cpp](https://github.com/ggml-org/llama.cpp), только `127.0.0.1` |
| Календарь | EventKit |

Запись ведётся потоково в WAV с регулярным обновлением заголовка: при аварийном завершении она
сохраняется и обрабатывается при следующем запуске. Результат каждого этапа обработки сохраняется отдельно.
